# 四柱八字互动式学习系统

一个基于子平派命理的渐进式、可交互学习网页。根据出生时间自动排盘，并按七层架构展示推导过程与横向知识。

## 核心功能

- **L1 排盘**：真太阳时校正、四柱干支、节气边界标注。
- **L2 五行**：天干+地支本气统计，五行分布图与日主占比。
- **L3 藏干 & 十神**：地支藏干矩阵、十神统计。
- **L3b 神煞**：天乙贵人、文昌、驿马、桃花、华盖、禄神等吉凶标签。
- **L4 日主强弱**：得令、得地、得势、得助四项评分。
- **L5 合会冲刑**：天干五合/四冲、地支六合/三合/三会/六冲/六害/三刑。
- **L6 大运 & 流年**：顺排/逆排、起运岁数、大运时间轴。
- **L7 综合判断**：格局、用神/喜神/忌神、行业方向建议。
- **横向知识面板**：点击推导中的术语，查看定义、出处、公式、案例。

## 技术栈

- 原生 HTML / CSS / JavaScript（ES Modules）
- 排盘引擎：6tail/lunar-javascript（已 vendored 到 `lib/`）
- 无构建步骤，无需安装依赖，可直接部署为静态站点

## 目录结构

```
bazi-learning/
├── index.html          # 入口页面
├── css/
│   └── styles.css      # 样式与传统主题
├── js/
│   ├── engine.js       # 八字计算引擎
│   ├── knowledge.js    # 知识图谱数据
│   ├── charts.js       # SVG 图表
│   ├── ui.js           # 渲染逻辑
│   └── main.js         # 入口
└── lib/
    └── lunar.js        # 农历/节气计算库
```

## 本地运行

任选一种方式：

```bash
# 1. Python 内置服务器
cd bazi-learning
python3 -m http.server 8080

# 2. Node 静态服务器（如果已安装 serve）
npx serve .

# 3. 直接打开 index.html（浏览器需支持 ES Modules）
```

然后访问 `http://localhost:8080`。

## 部署

将 `bazi-learning/` 目录部署到任意静态托管服务即可，例如：

- GitHub Pages
- Cloudflare Pages
- Vercel / Netlify
- CloudStudio 静态站点

## 使用说明

1. 输入出生日期、时间、性别与出生地经度。
2. 点击“开始排盘”。
3. 点击每层卡片中的“展开推导”查看计算过程。
4. 点击推导中的蓝色术语，在下方知识面板查看概念解释。
5. 点击顶部“一键展开”可展开所有推导。

## 注意事项

- 本系统以子平派为基础，部分细节（如藏干权重、神煞流派）不同书籍可能略有差异。
- 命理分析无标准答案，所有结果仅供学习参考，不构成人生决策依据。
